# Research

## Exploratory ESRD Clinical-Data Analysis

[Open the project](esrd-clinical-analysis/)

I explored how routine clinical and metabolomic measurements differ between people with end-stage renal disease and healthy controls. The project includes my paper, a short abstract, the figures I produced, and the notebooks used for the PCA workflow.

I have included the methods and code so that the analysis can be followed, while keeping the original research data out of this repository.
