# Research

## Exploratory ESRD Clinical-Data Analysis

[Open the complete project](esrd-clinical-analysis/)

This project explores routine clinical and metabolomic variables in end-stage renal disease and healthy controls. It contains a research paper, figures, a supporting abstract, and reproducibility-oriented notebooks for the PCA workflow.

### Included evidence

- Manuscript and research abstract
- Figure set referenced in the manuscript
- PCA data-preparation and visualisation notebooks
- Notes on data provenance, scope, and limitations
