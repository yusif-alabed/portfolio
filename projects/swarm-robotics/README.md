# Swarm Robotics CAD Prototype

I made this small, parametric robot design while exploring swarm robotics and engineering design. The model is included as both editable OpenSCAD source and an exported STL that can be viewed or 3D printed.

- [OpenSCAD source](cad/swarm_robot.scad)
- [STL model](models/swarm_robot.stl)

The `.scad` file can be opened and adjusted in [OpenSCAD](https://openscad.org/).
